# 🎯 Admin Guide - Creating Popular Trips

## How to Create Trips (Admin Only)

### Step 1: Access Admin Panel
1. Go to: `https://travel-tribe-eajn.onrender.com/admin/`
2. Login with your admin credentials

### Step 2: Create a New Trip
1. Click on **"Trips"** in the admin panel
2. Click **"Add Trip"** button (top right)

### Step 3: Fill in Trip Details

#### Basic Information
- **Destination**: Name of the place (e.g., "Goa", "Manali", "Dubai")
- **Category**: Choose "Within Country" or "Outside Country"
- **Start Date**: Trip start date
- **End Date**: Trip end date
- **Tribe Count**: Number of people in the tribe (default: 1)
- **Members Limit**: Maximum members allowed (default: 10)

#### Details
- **Description**: Write an engaging description about the trip
  - Example: "Experience the serene beaches and vibrant nightlife of Goa. Perfect for adventure seekers and beach lovers!"
- **Food Type**: Veg / Non-Veg / Both
- **Transport Modes**: Available transport options
  - Example: "Flight, Train, Bus, Taxi"

#### Recommendations
- **Must Visit Places**: Comma-separated list
  - Example: "Baga Beach, Fort Aguada, Dudhsagar Falls, Old Goa Churches"
- **Must Try Foods**: Comma-separated list
  - Example: "Fish Curry Rice, Bebinca, Prawn Balchão, Feni"

#### Media
- **Main Image**: Upload an attractive trip image
  - Recommended size: 1200x800px
  - Formats: JPG, PNG, WebP
  - Max size: 5MB

#### Additional Images (Optional)
- Click "Add another Trip image" to add gallery images
- Add captions for each image

### Step 4: Save the Trip
- Click **"Save"** to publish the trip
- The trip will appear on the homepage under "Popular Trips"

## Managing Trips

### View All Trips
- Go to Admin Panel → Trips
- You can see all trips with their details

### Edit a Trip
1. Click on the trip destination name
2. Make your changes
3. Click "Save"

### Delete a Trip
1. Select the trip(s) using checkboxes
2. Choose "Delete selected trips" from the action dropdown
3. Click "Go"

### Manage Members
- In the trip edit page, scroll to "Members" section
- Use the filter to add/remove users who have joined

## Tips for Creating Great Trips

1. **Use High-Quality Images**: Clear, attractive photos get more engagement
2. **Write Engaging Descriptions**: Tell a story, highlight unique experiences
3. **Be Specific**: Include dates, prices (if applicable), and detailed itineraries
4. **Update Regularly**: Keep trip information current
5. **Monitor Members**: Check who's joining and manage the member list

## Display on Homepage

Trips you create will appear in the **"Popular Trips"** section with:
- ✅ Main image
- ✅ Destination name
- ✅ Date range
- ✅ Food type
- ✅ Category badge
- ✅ Member count
- ✅ Join button for users

The tagline shows: **"Handpicked destinations curated by our team"**

## Need Help?

If you encounter any issues:
1. Check that all required fields are filled
2. Ensure image sizes are within limits
3. Verify dates are in the correct format
4. Contact support if problems persist
